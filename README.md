☕ Cafe Product Manager

A beautifully crafted Flutter app designed to manage cafe drink items efficiently with an intuitive and cozy user interface. Ideal for small cafe businesses or baristas looking to showcase and manage their beverage menu.

🔧 Features
🎨 Modern UI with a warm cafe-themed design.

📋 View list of available drinks.

➕ Add new drinks with name, description, image URL, and price.

📝 Edit existing drinks.

🧰 Getting Started
1. Clone the repository
git clone https://github.com/your-username/cafe-product-manager.git
cd cafe-product-manager

2. Install dependencies
flutter pub get

3. Run the app
flutter run
